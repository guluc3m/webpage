# JSON schema para datos
Usamos [JSON Schema](https://json-schema.org/specification) para añadir autocompletado y validación a los YAML de fortunas y actividades.

Ésto se aplica a nivel IDE, se recomiendan instalar las siguientes extensiones:
- VS Code: [`redhat.vscode-yaml`](https://marketplace.visualstudio.com/items?itemName=redhat.vscode-yaml)
- Neovim: [`yaml-language-server`](https://github.com/redhat-developer/yaml-language-server) ([`yamlls`](https://github.com/neovim/nvim-lspconfig/blob/master/lua/lspconfig/configs/yamlls.lua))
